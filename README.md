# MJl - DnD Generators

Модуль для Foundry VTT 14 и системы D&D5e 5.3.3. Первый генератор создаёт трофейную книгу заклинаний волшебника.

## Установка

В Foundry откройте «Дополнительные модули → Установить модуль» и вставьте адрес манифеста. Активируйте **MJl - DnD Generators** и **AG Fifthpendium** или **Fifthpendium** в мире D&D5e.

```text
https://raw.githubusercontent.com/MJl2517/MJl-DnD-Generators/main/module.json
```

## Книга заклинаний волшебника

1. Мастеру доступна кнопка с d20 на левой панели сцены. Откройте «Генераторы → Книга заклинаний волшебника».
2. Выберите тир партии и уровень владельца книги внутри тира. Тир I охватывает уровни 1–4, II — 5–10, III — 11–16, IV — 17–20.
3. Выберите обычную или вечную книгу. Галочки **Arcana Unleashed**, **Forgotten Realms** и **D&D Beyond** независимо включают классовые списки активных дополнений. Остальные активные библиотеки семейства Fifthpendium участвуют, если содержат классовый список волшебника.
4. Нажмите «Сгенерировать» для предпросмотра. Карточка с обложкой открывает исходную книгу в компендиуме. Кнопка «Создать предмет» сохраняет книгу во вкладке «Предметы» и добавляет ссылку на созданную книгу. Заклинания в предпросмотре и в предмете открываются по ссылкам.

Книга начинается с шести заклинаний первого круга. Каждый следующий уровень добавляет два разных заклинания доступного круга. Генератор сначала выбирает из высшего доступного круга и переходит к предыдущим, когда варианты заканчиваются. Дубликаты с одинаковым идентификатором сводятся к одной записи с приоритетом редакции 2024. Списки читаются из страниц класса в компендиумах.

Ориентир для продажи книги складывается из цены исходной карточки и 10 зм за каждый круг записанных заклинаний. Это оценка по стоимости резервного копирования знакомых заклинаний в D&D 2024. Расходы героя на переписывание всей книги показаны отдельно по 50 зм и 2 часа за круг каждого заклинания.

- [D&D 2024 Basic Rules · Wizard](https://www.dndbeyond.com/sources/dnd/br-2024/character-classes#Wizard)
- [donjon · 5e Random Generator](https://donjon.bin.sh/5e/random/#type=spellbook)
- [5E Magic Shop · Spellbook Generator](https://5emagic.shop/spellbook/generate)
